# UX Contribute

## Overview

Implements a design and commits them with Git flow a-la software engineer, but automated for less technical person. This allows non-software engineer be able to convert from a design and commit fully to an automated, CI/CD flow, while allowing software engineers to use it all the same.

## When to Use

Use this skill when:

- You want to contribute to HubSpot.
- You are not familiar on how to contribute to HubSpot.
- You _may_ not understand Git flow.
- You have a [HubSpot developer sandbox account](https://offers.hubspot.com/free-cms-developer-sandbox), or access to the production HubSpot account being used.
